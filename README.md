# Aplicacion_Movil_Reciclaje_Sexto_Semestre
Aplicación móvil desarrollada a lo largo de la materia Taller de Dispositivos Móviles, concebida como un proyecto integral para dominar desde los fundamentos de programación móvil hasta la integración con servicios en la nube. La lógica de la aplicación se programó en Java y el diseño de interfaces en XML bajo los lineamientos de Material Design, implementando diversos componentes visuales interactivos (botones, campos de texto, radio buttons, entre otros). Para la gestión de datos y servicios backend se integró la plataforma Google Firebase.
